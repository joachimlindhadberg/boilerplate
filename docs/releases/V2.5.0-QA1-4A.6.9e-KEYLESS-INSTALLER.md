## Exact changes

- Removes one-time installation/activation-key prompts, key generation, key-storage management and the obsolete `core/cli/install-key.php` utility.
- Reduces first-run wizard from four visible steps to **Database → Website & administrator → Complete** (two forms and a completion view).
- Moves read-only hosting preflight into the initial DB screen. Shows a compact expandable summary by default, automatically expands when requirements fail. The server enforces preflight at both database test and final install.
- Preserves the private-webroot requirement, explicit HTTPS for public hosts, opt-in loopback-only HTTP exception, strict session cookie flags, CSRF checks, database-schema-empty checks, InnoDB validation, exclusive .env creation, installer operation lock and refusal to re-run on configured sites.
- Regenerates session ID and CSRF token after a verified DB connection, before accepting administrator creation.
- No schema, migration, admin auth, session-manager runtime, frontend theme, upload directories, backup or content changes. Installer SCSS and compiled CSS remain byte-identical.

## Essential security trade-off

An unconfigured, publicly accessible site with a keyless installer **cannot authenticate who owns the server**. A stranger who completes setup first (potentially using a database the stranger controls) could become its initial administrator. CSRF, HTTPS, an empty-database check, private webroot and locking after first installation **do not remove this first-visitor takeover risk**. We do not claim otherwise.

To prevent that risk in practice, keep the new site behind a temporary host-side access restriction until setup completes, or upload/install immediately before publicly opening the domain. This must be tested with the user's hosting provider; an account-authenticated control-panel or authenticated deployment is a separate setup workflow, not provided by this candidate. A host restriction is *recommended* for high-security deployments; without it there is no reliable ownership verification during initial setup.
