# Boilerplate CMS V2.5.0 QA1 — 4A.6.9i3 Gallery UI & Core Icons

**Baseline:** 4A.6.9i2 UI test candidate; last user-approved baseline remains 4A.6.9h.
**Decision:** candidate for local QA, not production-approved.

## Scope

- Fix Gallery Page Builder display settings layout: Core Toggle for Fullscreen Lightbox and Autoplay, and explicit hidden-state CSS for settings/mode/interval areas. Forms preserve their field names, data hooks and existing saved JSON.
- Slider has modern theme-owned presentation: overlay round chevron buttons, bottom slide counter, and integrated pause/play controls. No autoplay by default.
- Slider buttons and Lightbox close/previous/next use Core's shared SVG icon registry. Lightbox JS clones inert Core SVG markup, never redefines icon paths or uses character glyphs.
- Core gallery manifest bumped to 1.0.17; legacy Gallery data, media references and database schema unchanged.
- SCSS source and compiled frontend CSS synchronized; Core admin CSS and SCSS remain byte-identical.

## Safety and compatibility

- Gallery module still outputs behavior and semantic HTML only. Frontend theme retains all gallery presentation CSS.
- Existing i2 gallery modes, autoplay configuration, Page Builder JSON and responsive image processing remain.
- Legacy pages remain supported; no migrations or database writes during upgrade packaging.
- Installer, uploads, media cleanup and other modules are not touched.

## Manual acceptance

1. On a fresh test page open Gallery in Page Builder. Choose Grid + Lightbox: only the column selector and a correctly-styled **Core Toggle** appear.
2. Choose Slider: only Autoplay appears; enable it and the interval selector appears. Disable it and the interval selector disappears. Confirm saving/reopening both modes.
3. In frontend, slider images are large and consistently cropped. Prev/next Core SVG arrows overlay the image; counter sits at bottom, not in a separate row.
4. Test play/pause Core SVG icons and autoplay at 3, 5 and 10 seconds, mouse hover, keyboard focus, window visibility and swipe.
5. Open Lightbox with one and multiple images: centered image, correct Core SVG close and arrows, keyboard Escape/left/right, contained/fullscreen.
6. Check desktop, mobile, customized frontend themes and keyboard focus; refresh CSS cache.
7. Existing saved galleries continue to work. Installation and media unaffected.

**Environment limit:** Headless Chromium timed out in the build environment; visual layout and full browser interactions require local QA. Public release remains NO-GO.
