# 4A.6.9i2 – Gallery Workflow Redesign

**Baseline:** user-approved 4A.6.9h. **Status:** isolated test candidate; local acceptance pending.

## User-facing behavior
- Gallery admin manages collection, status and image order only; it no longer exposes a Lightbox toggle.
- New Page Builder Gallery placements offer **Grid + Lightbox** (2–6 desktop columns, fullscreen by default) or **Slider** (manual controls, optional autoplay at 3–10 second intervals).
- Slider pauses on hover, keyboard focus, and hidden browser tabs; pause/play is always available when autoplay is selected. Swipe and arrow keys work.
- All styling remains owned by the frontend theme. The starter theme SCSS and compiled CSS were updated in sync.
- Existing placements retain historical gallery Lightbox state (and prior 4A.6.9i settings, if present) when merely resaved. Gallery DB column is retained for backward compatibility; no migration.
- No automatic deletion or migration of media, uploads, galleries or Page Builder JSON.

## Limitations
- Browser UI automation was blocked by the isolated environment. Test layout, persistence, responsive columns, fullscreen viewer, mobile swipe and autoplay using the local Mac deployment before acceptance.
- No real MySQL database setup was tested in this environment.
- Custom frontend themes require corresponding presentation styling for new modes.
