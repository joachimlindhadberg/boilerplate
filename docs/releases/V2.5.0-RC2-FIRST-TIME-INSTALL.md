# V2.5.0-RC2 – First-Time Installation Wizard

**Status:** Development / Production Candidate for owner local validation; not stable/go-live.

Base: user-approved V2.5.0-RC1 URL Configuration & Fallback; internal CMS version remains `2.5.0`.

Changes restricted to Phase 2:
- Dedicated `/install.php` standalone wizard (DB-independent bootstrap)
- Owner key authorization + CSRF, secure HTTPS-only public installation, no-cache/noindex
- DB connectivity test + strict empty-schema guard
- V2.5.0 empty baseline, one-time user+settings+home page creation and integrity triggers
- Historical migration checksums stored **only for the five migrations reconciled to the baseline**
- Atomic exclusive `.env` creation after verified installation, never overwrite existing `.env`
- New installation early routing; existing installations unchanged
- Source-only regression checks and scoped installer CSS/SCSS (identical), no Core UI redesign

**Limitations:** No local MySQL/mysqli environment was available to execute fresh-install DB integration. A real empty-database staging run and HTTP reverse-proxy testing are mandatory before production. MySQL DDL is irreversible on partial failure; installer does not attempt destructive automatic rollback.

See `docs/deployment/FIRST-TIME-INSTALL-RC2.md`.
