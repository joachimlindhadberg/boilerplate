# Boilerplate CMS v2.5.1-beta.2 – One-Click Update UI hotfix

QA pre-release, not production-approved.

## Runtime changes compared with v2.5.1-beta.1

1. The Updates page now renders the fully translated `admin_pull_notice()` `message`, retaining the existing success/error Core notice classes and escaping.
2. The available update heading and latest version are displayed only once. The View release and Update now actions remain available using existing Core UI. Prepared-only releases still show a single version.
3. Version identifier changed to `2.5.1-beta.2`.

No database migrations, schema changes or alterations to update download, verification, backup or installation code.

- `php tests/update-beta2-ui-notice-qa1.php` – 14 rendered-UI and source-safety checks.
